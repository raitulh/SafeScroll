# Chrome Web Store release checklist

## Extension behavior
- Manifest V3
- `activeTab` + `scripting`; no permanent broad host permissions
- User-initiated scans
- Local-first mode works without an account
- Enhanced mode clearly discloses that selected text can leave the device
- No remotely executed extension code

## Store assets to prepare
- 128x128 icon
- screenshots for Chrome Web Store
- concise single-purpose description
- privacy policy URL
- support URL
- permission justification
- data-use disclosures
- false-positive/false-negative safety notice

Human review and store approval are external steps and cannot be completed by source code alone.
