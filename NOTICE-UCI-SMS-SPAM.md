# UCI SMS Spam Collection attribution

SafeScroll's reproducible training/benchmark pipeline can consume the UCI SMS Spam Collection (dataset 228). UCI states that the corpus has 5,574 instances and is licensed CC BY 4.0. See: https://archive.ics.uci.edu/dataset/228/sms%2Bspam%2Bcollection

The project does not include the dataset bytes in the repository release by default. Fetch it with `python ml/fetch_public_data.py`, retain the attribution, and review the license requirements for your deployment.
